================================================================================
MAPLE & STONE — PREMIUM WEBSITE TEMPLATE
Complete specification for rebuilding this site from scratch
================================================================================

This document describes every design decision, code pattern, and implementation
detail used to build this site. Use it as a recipe to generate identical-quality
websites for other clients.


────────────────────────────────────────────────────────────────────────────────
SECTION 1: PROJECT TYPE & DESIGN BRIEF
────────────────────────────────────────────────────────────────────────────────

Site type:      Multi-page static HTML/CSS/JS (no build step, no framework)
Files:          index.html, about.html, services.html, articles.html,
                contact.html, styles.css, main.js
Business type:  Local service business (plumber, electrician, HVAC, contractor)
Audience:       Residential homeowners, 30-65, trust-driven decisions
Design read:    Premium local service site. Coal & Terracotta identity.
                Dark theme throughout. Editorial sans-serif typography.
                GSAP scroll animations. Floating glass pill nav.

Design dials (1-10 scale):
  DESIGN_VARIANCE:  8  (asymmetric layouts, varied section families)
  MOTION_INTENSITY: 7  (GSAP hero entrance + scroll reveals)
  VISUAL_DENSITY:   3  (generous whitespace, breathing room)


────────────────────────────────────────────────────────────────────────────────
SECTION 2: COLOR SYSTEM
────────────────────────────────────────────────────────────────────────────────

Strategy: Dark theme throughout. NOT warm cream/beige (banned AI default).
           One accent color only. All values in CSS custom properties.

CSS variable name    Hex value       Role
--------------------------------------------
--bg                 #111009         Page background (deep warm near-black)
--bg-2               #181511         Alternate section background (slightly lighter)
--bg-card            #1F1C18         Card / component surface
--bg-card-2          #252118         Alternate card surface
--ink                #F2EDE6         Primary text (warm off-white)
--muted              rgba(242,237,230,0.55)   Secondary text
--faint              rgba(242,237,230,0.32)   Tertiary text / labels
--copper             #C96942         Brand accent (terracotta/brick)
--copper-dim         rgba(201,105,66,0.18)    Accent tint background
--copper-line        rgba(201,105,66,0.30)    Accent border
--line               rgba(242,237,230,0.07)   Hairline borders
--line-mid           rgba(242,237,230,0.12)   Medium borders
--w                  1100px          Max content width
--ease               cubic-bezier(0.32,0.72,0,1)   All transitions

Replacing accent color for other clients:
  The --copper value (#C96942) is the single brand accent. To adapt for another
  business, change this one value and adjust --copper-dim and --copper-line
  proportionally. Keep the dark base palette the same.

Contrast verification:
  --ink on --bg:    17.2:1  (WCAG AAA - excellent)
  --muted on --bg:   5.4:1  (WCAG AA - passes)
  --copper on --bg:  4.8:1  (WCAG AA - passes for large text)

SECTION 3: TYPOGRAPHY
────────────────────────────────────────────────────────────────────────────────

Font stack:
  Display / headlines:  Plus Jakarta Sans (Google Fonts, weight 400-800)
  Body / UI:            DM Sans (Google Fonts, weight 400-600)

Google Fonts URL:
  https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@400;500;600;700;800&family=DM+Sans:opsz,wght@9..40,400;9..40,500;9..40,600&display=swap

Font preconnect tags (required in <head> before the font link):
  <link rel="preconnect" href="https://fonts.googleapis.com" />
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />

Type scale:
  h1:        clamp(2.8rem, 5.5vw, 5.5rem)   weight 800, tracking -0.03em
  h2:        clamp(2rem, 4vw, 3.8rem)        weight 800, tracking -0.03em
  h3:        1.05rem                          weight 700, tracking -0.02em
  hero h1:   clamp(2.8rem, 5.5vw, 5.5rem)   same as h1
  body:      1rem / line-height 1.6
  section-sub: 1.03rem / line-height 1.82, max-width 620px
  eyebrow:   0.67rem, weight 500, uppercase, tracking 0.16em, color --copper
  nav links: 0.82rem, weight 500

Rules:
  - h1/h2 use text-wrap: balance for even line breaks
  - Body text capped at 65ch line length
  - NO all-caps body copy
  - Hero headline max 2 lines at desktop
  - BANNED fonts: Inter, Roboto, Arial, Fraunces, Instrument Serif
  - Accent word in headlines: wrap in <span class="accent"> (renders in --copper)

Eyebrow rule:
  Maximum 1 eyebrow label per 3 content sections.
  If section A has an eyebrow, sections B and C directly after cannot have one.
  Use eyebrows to categorize only when the heading alone is insufficient.

SECTION 4: NAVIGATION
────────────────────────────────────────────────────────────────────────────────

Style: Floating glass pill, fixed, centered, detached from top edge

HTML structure:
  <nav class="site-nav" aria-label="Primary">
    <div class="nav-pill">
      [logo] [nav-links ul] [nav-cta div] [nav-toggle button]
    </div>
  </nav>

CSS key values:
  position: fixed
  top: 1.25rem
  left: 50%
  transform: translateX(-50%)
  width: calc(100% - 2rem)
  max-width: 1080px
  z-index: 200

Nav pill appearance:
  background: rgba(17,16,9,0.82)
  backdrop-filter: blur(22px) saturate(140%)
  border: 1px solid rgba(242,237,230,0.09)
  border-radius: 100px
  box-shadow: 0 8px 32px rgba(0,0,0,0.32)
  padding: 0.5rem 0.6rem 0.5rem 1.5rem
  display: flex, align-items: center, gap: 2rem

Logo (.nav-logo):
  font-family: Plus Jakarta Sans, weight 800
  font-size: 1.05rem, letter-spacing: -0.025em
  Trailing dot gets class="dot" which is styled with --copper color

Nav links (.nav-links):
  display: flex, gap: 0.15rem, centered with flex: 1 + justify-content: center
  Each link: 0.82rem, weight 500, color --muted, border-radius: 100px on hover

CTA area (.nav-cta):
  Two buttons: .btn.btn-ghost.btn-sm and .btn.btn-primary.btn-sm
  Flex-shrink: 0 so they don't compress

Mobile hamburger (.nav-toggle):
  Hidden on desktop (display: none in CSS)
  Shown at max-width: 760px
  Three spans that animate to X on .is-active state
  width/height: 2.5rem, border-radius: 100px

Hamburger line animations:
  span:nth-child(1) when .is-active: translateY(6.5px) rotate(45deg)
  span:nth-child(2) when .is-active: opacity 0
  span:nth-child(3) when .is-active: translateY(-6.5px) rotate(-45deg)

Current page: add aria-current="page" to the active nav link
  CSS: .nav-link[aria-current="page"] { color: --ink; background: rgba(242,237,230,0.07) }

Mobile full-screen overlay (#nav-overlay):
  position: fixed, inset: 0, z-index: 190 (below nav at 200)
  background: rgba(11,10,8,0.97), backdrop-filter: blur(24px)
  flex-direction: column, justify-content: center, align-items: center
  opacity: 0, pointer-events: none by default
  .is-open class sets opacity: 1, pointer-events: all

Mobile menu links (.nav-menu-link):
  font-family: Plus Jakarta Sans, weight 800
  font-size: clamp(2rem, 6vw, 3rem), letter-spacing: -0.03em
  color: --muted, transitions to --ink on hover
  opacity: 0 initially (GSAP animates them in)

Mobile overlay footer (.nav-overlay-footer):
  position: absolute, bottom: 3rem
  Contains a single .btn.btn-primary CTA (phone number)

JS behavior (in main.js):
  Toggle .is-open on overlay when hamburger clicked
  Set aria-expanded on toggle button
  Set document.body.style.overflow = 'hidden' when open
  GSAP stagger: nav-menu-link elements fade up (y: 30 to 0, stagger: 0.07)
  Close on link click, close on Escape key

SECTION 5: BUTTONS
────────────────────────────────────────────────────────────────────────────────

Base class .btn:
  display: inline-flex, align-items: center, justify-content: center
  font-family: DM Sans, weight 600, font-size: 0.88rem
  border-radius: 3px (sharp, consistent with card radius)
  padding: 0.62rem 1.25rem
  transition: background, border-color, color, transform, box-shadow
  All using --ease cubic-bezier(0.32,0.72,0,1)
  On :active: transform: translateY(1px) scale(0.99) (physical press feel)

Button variants:
  .btn-primary   background: --copper, color: #fff, border: --copper
                 hover: darker copper (#B85A37), box-shadow copper glow
  .btn-outline   background: transparent, color: --ink, border: --line-mid
                 hover: border rgba(242,237,230,0.28), faint bg
  .btn-ghost     background: rgba(242,237,230,0.06), color: --muted
                 hover: background 0.10 opacity, color: --ink
  .btn-lg        padding: 0.82rem 1.65rem, font-size: 0.96rem
  .btn-sm        padding: 0.44rem 0.9rem, font-size: 0.80rem

Rules:
  - Button text must NEVER wrap (white-space: nowrap)
  - All buttons: one line of text only, label max 3-4 words
  - Contrast: --copper bg with white text = 4.8:1 (passes large text AA)
  - Never mix two CTAs with the same intent on the same page

SECTION 6: PAGE STRUCTURE & SECTION LAYOUTS
────────────────────────────────────────────────────────────────────────────────

HTML boilerplate for every page:
  <!DOCTYPE html>
  <html lang="en" class="no-js">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>[Page Title] | [Business Name] — [City, State]</title>
    <meta name="description" content="[150-160 char description]" />
    [preconnect tags]
    [Google Fonts link]
    <link rel="stylesheet" href="./styles.css" />
  </head>
  <body class="no-js">
    [nav]
    [mobile overlay]
    <main>
      [sections]
    </main>
    [footer]
    [GSAP scripts deferred]
    <script src="./main.js" defer></script>
  </body>
  </html>

Note: html AND body both start with class="no-js". main.js removes this class
      on load and adds "js-loaded" for CSS/GSAP coordination.

GSAP CDN scripts (placed before main.js, all deferred):
  <script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/gsap.min.js" defer></script>
  <script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/ScrollTrigger.min.js" defer></script>

Section padding:
  .section       { padding: 7rem 0 }    standard
  .section-warm  { padding: 7rem 0; background: --bg-2 }    alternate bg
  At mobile (max-width: 760px): reduced to padding: 5rem 0

Container: max-width: 1100px, margin: 0 auto, padding: 0 2.5rem

Section alternation pattern (to avoid theme flips):
  All sections use the dark theme family (--bg or --bg-2), NEVER a light section
  between dark ones. Use bg-2 (#181511) for visual separation without theme flip.

Section layout families used (must vary — no two consecutive identical layouts):
  1. Hero:            Asymmetric split (55fr/45fr grid)
  2. Stats strip:     Horizontal 3-cell grid
  3. Problem grid:    2x2 CSS grid with alternating dark/light cells
  4. Editorial split: 1.15fr/0.85fr two-column with quote card
  5. Values grid:     3x2 CSS grid with floating oversized numbers
  6. Services bento:  Asymmetric CSS grid (1.5fr/1fr, featured cell spans 2 rows)
  7. Process steps:   3-column with horizontal connector line
  8. Post list:       Vertical editorial list with hover indent
  9. Area split:      1fr/1fr with photo (aspect-ratio 4/3)
  10. Testimonials:   Large display-type quote
  11. FAQ:            Accordion list max-width 760px
  12. CTA band:       Dark card, flex space-between
  13. 6-step grid:    3x2 grid (services page)
  14. 4-step grid:    4-column (contact page)
  15. 2x2 depth quad: Services problems grid

SECTION 7: HERO (HOME PAGE)
────────────────────────────────────────────────────────────────────────────────

Layout:
  display: grid
  grid-template-columns: 55fr 45fr
  min-height: 100dvh   (NEVER h-screen — use 100dvh for iOS Safari stability)
  padding-top: 6rem    (clears the floating nav)

Background:

    using rgba(201,105,66,0.06) and rgba(201,105,66,0.04)
    to add subtle depth without obvious gradients

Left column (.hero-content):
  flex-column, justify-content: center
  padding: 4rem [clamp(2rem,6vw,4rem)] 5rem [clamp(2rem,9vw,5.5rem)]
  
  Elements (in order, max 4 text elements in hero):
    1. .hero-badge     — pill badge, NOT uppercase/tracked (not an eyebrow)
    2. .hero-h1        — headline, max 2 lines at desktop
    3. .hero-sub       — subtext, max 20 words, color --muted
    4. .hero-cta-group — primary + secondary CTA buttons

Hero badge (.hero-badge):
  background: rgba(201,105,66,0.10)
  border: 1px solid rgba(201,105,66,0.22)
  border-radius: 100px  (pill shape)
  padding: 0.32rem 0.9rem
  font-size: 0.75rem, weight 500, color rgba(201,105,66,0.9)
  Content: "Licensed & insured · Raleigh, NC"  (max 1 middle dot separator)

Hero image (.hero-image-side):
  position: sticky, top: 0, height: 100dvh
  Contains .hero-img-clip which has clip-path: inset(0 0 0 0) by default
  The ::after pseudo overlays a gradient fade on the left edge:
    background: linear-gradient(to right, --bg 0%, transparent 18%)
    This blends the image into the dark background
  img: width/height 100%, object-fit: cover

GSAP hero animation (in main.js, runs on page load):
  Checks: const heroH1 = document.querySelector('.hero-h1')
  If exists AND motionOK (no prefers-reduced-motion):
  
  Timeline (gsap.timeline, ease: 'power4.out'):
    1. .hero-badge     fromTo y:16,opacity:0  → y:0,opacity:1  duration:0.6 delay:0.1
    2. .hero-h1        fromTo y:64,opacity:0  → y:0,opacity:1  duration:1.05
    3. .hero-sub       fromTo y:32,opacity:0  → y:0,opacity:1  duration:0.72
    4. .hero-cta-group fromTo y:20,opacity:0  → y:0,opacity:1  duration:0.55 stagger:0.12
  
  Parallel hero image reveal:
    gsap.fromTo('.hero-img-clip',
      { clipPath: 'inset(100% 0 0 0)' },
      { clipPath: 'inset(0% 0 0 0)', duration: 1.35, ease: 'power4.inOut', delay: 0.05 }
    )
  
  The image clip-path starts at 100% (fully hidden, clipped from top)
  and reveals downward to 0% over 1.35 seconds. Cinematic wipe effect.

CSS fallback (no JS):
  html.no-js .hero-h1  animates via @keyframes heroFadeUp  (y: 48px → 0, fade in)
  Only fires under @media (prefers-reduced-motion: no-preference)
  Wrapped in html.no-js selector — removed by JS on load

────────────────────────────────────────────────────────────────────────────────
SECTION 12: SCROLL ANIMATIONS (main.js)
────────────────────────────────────────────────────────────────────────────────

Library: GSAP 3.12.5 + ScrollTrigger plugin (both from cdnjs CDN, deferred)

Reduced motion check (MUST be first):
  const motionOK = !window.matchMedia('(prefers-reduced-motion: reduce)').matches
  All animation code is wrapped in: if (motionOK) { ... }

Data attribute system for scroll reveals:
  [data-reveal]          Single element fade+translate reveal
  [data-reveal-heading]  Section heading variant (slightly different easing)
  [data-reveal-stagger]  Parent container for staggered children
  [data-stagger-item]    Child element within a stagger group

Optional modifiers on [data-reveal]:
  data-reveal-y="60"        Custom Y offset in pixels (default 40)
  data-reveal-dur="0.9"     Custom duration in seconds (default 0.75)
  data-reveal-delay="0.1"   Custom delay (default 0)

All scroll reveals use:
  opacity: 0 → 1
  y: [offset]px → 0
  ease: 'power3.out'
  scrollTrigger: { start: 'top 88%', once: true }
  The 'once: true' prevents re-triggering on scroll back up

Stagger reveals:
  gsap.utils.toArray('[data-reveal-stagger]') loops all containers
  finds children with [data-stagger-item]
  fromTo: opacity 0→1, y 32→0, stagger: 0.08, ease 'power3.out'
  scrollTrigger: start 'top 85%', once: true

Inner page hero animation:
  Targets .eyebrow, h1, .section-sub inside .page-hero
  fromTo: y:36,opacity:0 → stagger, delay 0.2s

Safety checks:
  if (typeof gsap === 'undefined') return  — handles CDN failure
  if (typeof ScrollTrigger !== 'undefined')  — before registerPlugin call
  All scroll reveal code: if (motionOK && typeof ScrollTrigger !== 'undefined')

BANNED animation patterns (never use):
  window.addEventListener('scroll', ...)  — causes jank
  useState to track scroll position       — re-renders on every frame
  Animating top, left, width, height      — causes layout reflow
  Only animate: transform and opacity

SECTION 17: ADAPTING FOR OTHER CLIENTS
────────────────────────────────────────────────────────────────────────────────

To use this template for a different local service business:

STEP 1 — Change the accent color
  In styles.css, update:
    --copper:      [new hex]
    --copper-dim:  rgba([R],[G],[B],0.18)
    --copper-line: rgba([R],[G],[B],0.30)
  Everything else stays dark. The single accent permeates all components.

STEP 2 — Change fonts if needed
  Replace Plus Jakarta Sans with another premium grotesque:
    Options: Geist, Outfit, Cabinet Grotesk, Satoshi, GT Walsheim
  Update Google Fonts URL in all HTML files
  Update font-family references in styles.css (h1,h2 and .nav-logo and .footer-brand-name)

STEP 3 — Replace all copy
  Keep the SAME section structure and layout families
  Replace only: business name, tagline, service names, copy, phone, email, city

STEP 4 — Replace images
  Hero image (hero-img-clip img src):
    Use Unsplash with direct URL or generate with image tool
    Choose an image that fills a tall vertical frame (portrait orientation preferred)
  Service area photo (area-photo img src):
    Local neighborhood / exterior photo

STEP 5 — Update meta tags
  Title: [Business Name] | [Service Type] in [City, State]
  Description: 150-160 chars, includes city + main services
  Update all 5 HTML files

STEP 6 — Update nav active state
  Each page: add aria-current="page" to the matching nav link

STEP 7 — Update footer hours
  Adjust Mon-Fri and Sat hours to match client

Other businesses this template fits well:
  Electrician, HVAC contractor, roofer, pest control,
  handyman service, lawn care, painting contractor,
  any residential home services business

Dark theme rationale for this template:
  Most local service competitors use light, generic, template-looking sites.
  A dark theme is immediately distinctive and reads as more premium.
  The single terracotta/copper accent creates warmth and craft association.
  Change the accent to deep teal, slate blue, or forest green for other trades.
